## What I'm building

**TempesT – Fretes & Frotas** · B2B SaaS for freight and fleet management
Multi-tenant platform for transport companies: customers, vehicles, drivers, carriers, freight lifecycle, expenses and payments, with role-based access (admin, manager, operator, finance), audit history, CSV import/export, dashboard alerts and a mobile-friendly driver portal (PWA). *Source code is private.*

**Financeiro e Frota Logística** · [frota-financeiro](https://github.com/benimaru0101-collab/frota-financeiro)
React Native / Expo app for financial and fleet management, built as a university project.
